为了让开发者更方便开发小程序，开发者工具提供了对音视频处理相关的小程序API的支持

> 工具从 1.03.2004292 版本开始，支持了音视频合成API

## 运行环境

- 下载并安装ffmpeg

## 安装ffmpeg步骤

### Mac

Mac可以直接使用homebrew安装ffmpeg

打开终端输入以下内容并运行
```bash
brew install ffmpeg
```

### Windows

前往官网下载ffmpeg并安装 [下载地址](https://www.ffmpeg.org/download.html)

选择static版本

下载解压到所选目录后，配置环境变量

1. 单击此电脑，单击右键

2. 单击菜单里的属性，单击高级系统设置

3. 单击环境变量。在用户变量里，找到并选择 Path 环境变量，单击编辑。如果 Path 环境变量不存在，请单击新建。

4. 在编辑用户变量（或新建用户变量）窗口中，ffmpeg解压后的路径\bin，单击确定保存。 ![配置环境变量](https://res.wx.qq.com/wxdoc/dist/assets/img/ffmpeg_path_env.1a0d905f.png)

配置完成后，打开终端输入以下命令，能正确输出信息后，重启微信开发者工具即可
```bash
ffmpeg -version
```
