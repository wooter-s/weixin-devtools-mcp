## 将任务所有图片均设为基线图片

#### 简要描述

将某个任务下面的所有图片，全部设为基线图片，方便其他任务和它对比

#### 请求URL

- `https://minitest.weixin.qq.com/thirdapi/set_plan_image`

#### 请求方式

- POST

#### 参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| **token** | 是 | string | 可以从页面右上角头像下拉菜单中的 “我的信息”，跳转至我的信息页面，查看“我的Token” |
| **group_en_id** | 是 | string | 项目英文ID，可在 项目管理/产品管理 页面获取 |
| **plan_id** | 是 | int | 需要设置的测试任务ID |

#### 返回示例
```python
{
    "msg": "修改成功",
    "rtn": 0,
    "timestamp": 1649313364.4696019

}
```

## 重新对比任务图片

#### 简要描述

一般用于在重新设置基线图片后，可调用本接口，对某个任务下的图片重新对比。如果任务未结束，或者已经在重新对比中，会返回失败

> 特别注意：本接口调用后，会将任务的所有图片重新和基线图片对比，任务状态会由测试完成变更为任务对比中，

#### 请求URL

- `https://minitest.weixin.qq.com/thirdapi/re_diff_plan_image`

#### 请求方式

- POST

#### 参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| **token** | 是 | string | 可以从页面右上角头像下拉菜单中的 “我的信息”，跳转至我的信息页面，查看“我的Token” |
| **group_en_id** | 是 | string | 项目英文ID，可在 项目管理/产品管理 页面获取 |
| **plan_id** | 是 | int | 需要设置的测试任务ID |

#### 返回示例
```python
{
    "msg": "已开始重新对比图片，敬请耐心等待",
    "rtn": 0,
    "timestamp": 1649313364.4696019

}
```

## 删除备选的基线图片

#### 简要描述

随着时间推移，自动化任务越跑越多，备选的基线图片也日益增加。

虽然云测提供了多种筛选能力，但是在选择基线图片时，很旧的基线图片，会干扰选择。

此时可以调用本接口，删除某个任务的备选基线图片，或者删除目前所有的备选基线图片

> 特别注意：删除后，备选基线图片无法恢复，请慎重选择

#### 请求URL

- `https://minitest.weixin.qq.com/thirdapi/del_plan_image`

#### 请求方式

- POST

#### 参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| **token** | 是 | string | 可以从页面右上角头像下拉菜单中的 “我的信息”，跳转至我的信息页面，查看“我的Token” |
| **group_en_id** | 是 | string | 项目英文ID，可在 项目管理/产品管理 页面获取 |
| **plan_id** | 否 | int | 需要设置的测试任务ID。请注意：如果没有传入plan_id，表示删除所有备选基线图片 |

#### 返回示例
```python
{
    "msg": "成功删除了xx个备选图片",
    "rtn": 0,
    "timestamp": 1649313364.4696019

}
```
