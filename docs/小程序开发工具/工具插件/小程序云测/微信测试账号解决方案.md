# 微信测试账号解决方案

云测服务提供两种测试账号供开发者使用：

- 使用虚拟账号测试

- 使用自己真实微信号测试

请注意： 当**同一项目**中，用**同一账号**提交多台机器任务时，云测服务会自动对测试账号进行**排队处理**，测试耗时会成倍增加

## 虚拟账号测试

虚拟账号是使用开发者工具中，多账号调试能力提供的虚拟账号进行测试，虚拟账号对不同小程序是独立的。具体使用文档可以参考 [使用虚拟账号测试](./virtual_test.html)

### 优势

- 提供24个虚拟账号，方便构造丰富的测试场景

- 可以在开发者工具上配置测试数据，方便团队共享

### 缺点

- 虚拟账号绑定的是虚拟手机号，无法接受手机验证码，如果需要验证码才能完成登录逻辑的小程序，需要自己进行mock处理。这种情况建议使用真实账号测试，如必须使用虚拟账号，具体操作可参考 [虚拟账号手机号Mock方案](./phone_mock.html)

## 真实微信号测试

> 请注意本功能正在内测中，请前往 需要帮助，加入官方企业微信群，联系MiniTest小助手申请

云测服务也支持用户使用真实微信号测试，具体使用可以参考文档 [使用真实账号测试](./mock_real_account.html)

### 优势

- 使用用户自己的真实账号可以解决手机验证码的问题

- 用户无需迁移测试账号的测试数据，降低使用成本

### 缺点

真实账号使用有以下限制：

- 微信号必须是 [微信开发平台](https://mp.weixin.qq.com/)中，该小程序的 **开发者或者管理员**

- 账号有一定的有效期，目前是30天，当账号过期或者账号失效时，需要用户重新扫码授权
