# AI自动化测试

AI自动化测试是云测利用大模型能力，对在自动化测试方向进行探索，目前主要包括：

- **AIMonkey**：用大模型能力重构Monkey测试能力

- **AI自定义测试**（内测中）：用户只需提供用例的自然语言描述，云测会根据描述，用大模型能力，使用Minium驱动用例执行
