云测服务支持配置邮箱及手机号信息，测试任务结束会自动以短信或者邮件方式通知到用户

# 配置方式

进入云测插件，点击右上角头像 **我的信息**，跳转至我的信息页面，**绑定手机号/邮箱**，输入手机号/邮箱，**发送验证码**，获取验证码并输入，绑定用户信息

![图片](https://res.wx.qq.com/wxdoc/dist/assets/img/notice1.0022713d.png)

# 通知示例

在任务结束时，自动发送通知到用户

![图片](https://res.wx.qq.com/wxdoc/dist/assets/img/notice2.4b52b086.png)

# 解除绑定

绑定手机后，如果希望不在接收相同通知，可以点击解除绑定按钮，来解绑手机号或邮箱

# 配置任务结束通知方式

云测支持项目可以配置任务结束后的通知方式：

- 全部通知

- 仅失败通知

- 不通知

需要配置的用户可以在项目中的左侧导航栏，点击 **项目管理** => **产品管理**，在任务结束通知中配置
