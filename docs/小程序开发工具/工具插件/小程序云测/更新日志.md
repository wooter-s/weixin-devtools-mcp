## 2023.03.23

1. `A`智能化Monkey **报告全面升级**，将体验评分发现的性能问题暴露在外层问题列表中，并且支持按照页面维度查看发现的问题，详情可参考 [智能化Monkey](./monkey.html)

2. `A`智能化Monkey和启动性能分析任务， **支持用户选择跑测机器数量**，最多不超过10台。后台会 **随机选择机器**测试。如希望指定机型测试，可参考 [购买额外时长](./minitest/buytime.html)

3. `A`解决用户上传Minium脚本时，无法安装第三方库的问题，并默认安装包增加了100+库，满足绝大部分的项目需求，详情看参考 [上传自定义测试用例指引](./upload_case.html)

4. `A`增加 **新增，查询，修改测试计划**的第三方接口，详情可参考 [测试计划相关接口](./api_test_plan.html)

5. `F`修复录制回放转化用例的相关Bug，提升录制回放任务的稳定性

## 2023.02.06

#### 近期小程序云测试服务新增以下特性

1. `A`支持智能化Monkey配置前置步骤，详情可参考 [智能化Monkey扩展](./customize_monkey.html)

2. `A`启动性能优化，增加和现网 `同机型`数据对比，更加准确

3. `A`重跑启动性能任务时，默认用原机型重跑，方便用户对比分析数据

4. `A`真实账号支持配置mock地理位置等信息

5. `A`任务执行超过3小时还未结束，支持用户手动终止任务。任务终止后，会将目前测试结束的用例结果整合到测试报告中，未测试或者正在测试的用例结果丢弃

## 2022.12.26

#### 近期小程序云测试服务新增以下特性

1. `A`支持使用 **用户真实微信号测试**，解决虚拟账号无法接受验证码问题

2. `A`启动性能支持和We分析现网同档次机型数据对比，及时发现当前版本的启动性能问题

3. `A`体验评分能力优化，重新划分评分项目，从性能检查，异常检查和最佳实践三个方面整合评分项目，帮助用户更好发现运行时性能问题

4. `A`对于付费用户，支持录制回放以及Minium使用多台机型跑测兼容性测试用例

#### 修复或优化以下问题

1. `U`Minium测试报告优化，支持展示用例描述，增加小程序日志展示

2. `U`优化Monkey任务的测试报告，增加网络请求日志展示

3. `U`Sourcemap上传操作优化，增加loading状态，优化上传删除操作流程

4. `F`修复录制回放底层的一些问题，提升回放成功率

## 2022.08.31 更新说明

#### 近期小程序云测试服务新增以下特性

1. `A`支持设置定时测试能力，支持一次性预约任务，或按照每天或每周定时执行测试任务

2. `A`支持上传Sourcemap解析JSError报错信息

3. `A`录制回放新增模块化配置能力，支持增加通用模块和全局模块，提升用户录制效率

4. `A`录制回放支持统一修改用例目标对象，降低用例维护成本

#### 修复或优化以下问题

1. `U`测试报告页面优化，如Minium任务增加teardown时页面wxml信息下载，方便用户排查元素找不到的问题

2. `U`录制回放任务稳定性优化，如修复原生授权弹框，工具录制的文案和手机实际的文案不一致，导致云测点击失败的问题

## 2022.06.15 更新说明

#### 近期小程序云测试服务新增以下特性
