## 购买云测

当[免费时长](./test_time.html)不够时，云测服务支持2中购买方式：

- [购买额外时长](./buytime.html)

- [购买专有云](./buyphone.html)

## 购买方式对比

两种购买方式对比如下：

| 对比项目 | 购买专有云 | 购买额外时长 |
| --- | --- | --- |
| 测试时长 | **无限制**，类似包月模式 | 购买的套餐时长+每周免费赠送时长 |
| 使用项目 | 可为**多个项目**配置专有云测试 | 购买时长时需指定项目。如有多个项目，需要分别购买 |
| 机器共享 | 专有云机器仅配置的项目**专机专用**，不和其他项目共享 | 所有项目共享公有云，如其他项目占用机器，需排队等待 |
| 快速测试模式 | 支持 | 支持，需要选快速测试云的机器 |
| 可选机型 | 只能选择购买的专有云机型测试，**每月可更换一次机型** | 可选择公有云 **300+种机型** 测试 |
| 远程手动操作真机 | **支持** | 不支持 |
| 详细文档 | [购买专有云](./buyphone.html) | [购买额外时长](./buytime.html) |

## 建议：

如果项目主要使用云测做自动化回归测试，对兼容性测试不敏感，且项目使用量大，或者有多个项目共同使用的需求，建议购买购买云

如果项目希望做指定机型的兼容性测试，或者希望提升测试速度，建议购买额外时长

## 常见问题：

#### 1. 我想用专有云做回归测试，同时也希望使用额外时长做兼容性测试，请问可以支持吗？

云测**支持同时购买购买2种方案**，用户可以自由切换使用的模式

具体来说，前往“项目管理”=>“产品管理”页面，配置`是否停用专有云`选项:

- **不停用**：继续使用专有云模式，时长无限，适合回归测试场景

- **停用**：停止使用专有云，恢复到使用时长模式，适合跑测兼容性测试场景

> 请注意：本选项只对购买专有云的项目开放
